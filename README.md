# BIOPRESS Analytics
### Smart Hospital Hand Hygiene Monitoring & Infection Control System

## 1. Project Overview

BIOPRESS Analytics is a healthcare-focused database application designed to support infection prevention and control in hospitals by monitoring hand hygiene compliance among healthcare workers, especially nursing staff.

Hand hygiene is one of the most important practices for preventing healthcare-associated infections (HAIs). However, monitoring whether healthcare workers properly clean or disinfect their hands before and after patient-care activities can be challenging.

BIOPRESS provides a structured system for recording hand hygiene observations, organizing hospital data, and analyzing compliance across different hospital departments and healthcare professional categories.

The system helps infection control teams understand compliance patterns, identify areas that need improvement, and support better infection prevention decisions.

## 2. Project Objectives

- Monitor hand hygiene compliance among healthcare workers.
- Record hand hygiene observations in a structured database.
- Analyze compliance across different hospital wards and shifts.
- Identify patterns in hand hygiene practices.
- Support infection control teams with organized data and analytical reports.
- Improve hospital infection prevention and patient safety.

## 3. Key Features

- **Hand Hygiene Monitoring:** Organizing observations of healthcare workers' hand hygiene practices.
- **Data Management:** Structured storage and management of hospital observation data.
- **Compliance Analytics:** Analyzing hand hygiene performance and compliance rates.
- **Ward-Based Analysis:** Comparing results across different hospital departments.
- **Shift-Based Analysis:** Understanding compliance patterns across working shifts.
- **Professional Category Analysis:** Evaluating observations across different healthcare worker categories.
- **Secure Access:** Role-based access control for different system users.
- **Database Management:** Relational database design and structured data handling.

## 5. Database Design

The project focuses on designing and implementing a structured relational database to manage hospital hand hygiene observation records.

The database supports organizing and analyzing observations using different attributes, including:

- Ward
- Professional Category
- Shift
- Hand Hygiene Indication
- Observation ID

The database design also supports structured querying and analytical operations to generate useful compliance insights.

## 6. Hospital Departments

The project dataset includes observations from the following hospital departments:

- Obstetrics and Gynecology (Ob/Gyn)
- Paediatric
- Medical
- Surgical
- Neonatal Intensive Care Unit (NICU)

- Password hashing.
- JWT-based authentication.
- Audit logging.

## 9. Project Goals and Impact

BIOPRESS Analytics aims to help hospitals improve infection prevention practices by transforming hand hygiene observation records into organized and meaningful information.

By providing structured data management and analytical capabilities, the system can help infection control teams identify compliance gaps and make more informed decisions.

**The ultimate goal is to support better hand hygiene practices, reduce the risk of healthcare-associated infections, and improve patient safety.**
